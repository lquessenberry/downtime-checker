First public alpha of the native **Global Status** apps (globalstatus.app), built in Rust from the `rust/native-core` branch. Free and open source: FOSS first, with any paid enhancements only ever as optional add-ons.

> **Alpha, unsigned builds.** These binaries are not code-signed or notarized yet.
> - **macOS:** Gatekeeper will say the app "cannot be opened" or is from an unidentified developer. Right-click (Control-click) **Global Status.app → Open → Open**, or allow it under System Settings → Privacy & Security. The app is ad-hoc signed only.
> - **Windows:** SmartScreen may show "Windows protected your PC". Click **More info → Run anyway**.
> - **Android:** the APK is signed with a throwaway debug key made on the build server (`-debugsigned`). Enable installs from unknown sources to try it. A later build signed with the real release key will not install over it; uninstall first.
> - Check downloads against `SHA256SUMS`.

## What works
- **Native globe (`downtime-globe`)**: wgpu + egui window with a lit, graticuled 3D globe, drag to rotate, scroll/pinch to zoom, capital pins with hover labels and click-to-select, and the category search counts.
- **Catalogs built in**: the country and category catalogs (governments, banks and exchanges, transportation, utilities, communications, medical, education, military, stores, food, shipping, weather) are compiled into the app, so it runs with no data folder. `--root DIR` loads a catalog folder instead; `--summary` prints counts without a window.
- **`downtime` CLI**: the same numbered menus as `downtime.py`: ping, then TCP 443, then TCP 80, UP/DOWN per site, grouped by country and state.
- **`downtime-server`**: SSE server with the same `/api/*` routes as the Node visualizer.
- **Platforms**: Linux x86_64 (tar.gz and AppImage), Windows x86_64 (zip), macOS universal Apple Silicon + Intel (zip and dmg), Android 7.0+ (universal APK: arm64-v8a, armeabi-v7a, x86_64).

## Not there yet
- No imagery, terrain or coastlines on the native globe yet (shaded sphere + graticule).
- No live layers in the native apps yet: outages, aircraft, ships, weather, hazards, conflict and humanitarian data are on the web globe at https://globalstatus.app and come to native in later phases (see `docs/rust-native.md`).
- The Android app shows the globe and pins only; it has no network access or permissions yet.
- No code signing, notarization or auto-update yet.
- Not on F-Droid yet; metadata is prepared in `fastlane/` and `fdroid/`.

## Data sources and credits
- Site catalogs (`*.txt`) are compiled by the project from public websites; the CLI checks reachability with ICMP ping and TCP 443/80.
- Location lookups in the CLI use [ipwho.is](https://ipwho.is) and are cached locally in `locations.json`.
- Built with Rust, [wgpu](https://wgpu.rs), [egui/eframe](https://github.com/emilk/egui), [glam](https://github.com/bitshifter/glam-rs), tokio and rustls.
- The web globe's data feeds and their licenses are listed in `docs/DATA-SOURCES.md`.

Everything the apps store stays on your device.
